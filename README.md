# Alex | AI & Full-Stack Software Developer

My Personal portfolio, featuring two AI-focused products: **Jelaksy**, an AI project manager, and **Lurkk**, an AI scheduling agent that uses natural-language requests.

The site is a responsive, animated single page built with Next.js and Framer Motion. Product interface visuals are illustrative mockups, not live demos or screenshots of the actual products.

## Featured Projects

### Jelaksy

An AI project manager that turns project context into clearer priorities and practical next steps.

**Stack:** Next.js, React, TypeScript, Tailwind CSS, Node.js, PostgreSQL, Prisma, Ollama API.

### Lurkk

An AI scheduling agent that interprets natural-language requests and works with Google Calendar.

**Stack:** HTML, CSS, JavaScript, Python, Google Calendar API.

## Tech Stack

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion for animation
- React Icons for social icons

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server. |
| `npm run lint` | Run ESLint. |
| `npm run build` | Create a production build. |
| `npm start` | Serve the production build. |

## Personalize

Update the project descriptions, technology stacks, contact email, and social profile URLs in `app/page.tsx`. Global styles and responsive layouts are in `app/globals.css`.
Page title and description are in `app/layout.tsx`.

## Deployment

Build the site with `npm run build`, then run `npm start` or deploy it to a platform that supports Next.js.
